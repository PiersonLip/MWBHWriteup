# Common-envelope efficiency (`α_CE`)

## Purpose

Show that α_CE rearranges who survives / merges more than it changes remnant masses.

## DOM / code

- Slider for α_CE
- Canvas: `#ce-canvas` (toy inspiral schematic)
- Meter: `#ce-meter`, `#ce-survive`, `#ce-merge`
- Bars: `#ce-bars` (relative channel shifts)

## Behavior

- Lower α → deeper inspiral → more mergers, fewer detached unequal systems (qualitative).
- Bars are schematic multipliers keyed off α, not full POSYDON reruns.
